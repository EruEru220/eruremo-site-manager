環境を確認しています…

ここはステージング（確認用の非公開環境）です
  • Cloudflare Access で保護された、自分だけが見られる確認用の環境です。
  • 公開サイトではありません。ここでの変更が公開サイトに出ることはありません。
  • R2（画像の保管庫）は接続済みです。
  • 現在、画像の書き込み・削除は安全のため停止しています。
  • 画像一覧・読み出しのみ利用できます。
ここはローカル開発用の画面です
  • 自分のパソコンの中だけで動いています。
  • 本番の Cloudflare・R2 にはつながっていません。
  • 画像は worker/.wrangler/state/ の中に保存されます。
環境を確認できませんでした
  • /api/health に応答がないため、どの環境かを判断できません。
  • どの環境か分かるまで、画像のアップロード・削除・移行は行わないでください。
編集ツールをひらく

eruremo_SiteManager.html

ここから開くと、画像が自動でローカルR2へ保存されます（同じ住所なので通信できます）。 ファイルをダブルクリックして開いた場合は、今までどおり画像が HTML の中に 埋め込まれます（どちらでも作業できます）。

画面の見た目や操作の確認に使えます。保管庫への書き込みを止めているので、 画像を選ぶと「保管庫に保存できません」と表示され、これまでどおり HTML の中に埋め込まれます。すでに保管庫にある画像は、一覧でも表示でも見られます。

いまできること
  • GET /api/health — 疎通確認
  • POST /api/media/upload — 画像アップロード
  • GET /api/media — 保管庫の画像一覧
  • DELETE /api/media/item — 画像を1枚削除
  • GET /media/… — 保存した画像の読み出し

ステージングでは、読み出し（一覧・画像）は使えますが、 書き込み（アップロード・削除）は停止中です。 止まっている間は保管庫に一切アクセスしません。
