対象：`eruremo_SiteManager.html`

## この文書の目的

## 11. 自動テスト候補（Phase 2 以降で導入する場合）

現在は依存ゼロなので、導入するなら**最小構成**を推奨します。

### 純粋関数のユニットテスト 🤖

これらは DOM に依存しないため、単体で切り出せば Node.js だけでテストできます。

| 関数 | テスト観点 |
|---|---|
| `clone()` | 深いコピー・文字列参照の共有 |
| `migrate()` | 欠損キーの補完・既存値の保持・配列の型保証 |
| `get()` / `set()` | ドット記法・中間オブジェクトの自動生成 |
| `fixUrl()` | 各種スキームの扱い |
| `escAttr()` / `escHtml()` | 5文字のエスケープ |
| `buildJsonLd()` | 有効なJSON・Event の条件分岐・`</script` の無害化 |
| `contrast()` / `hex2rgb()` | 既知の色でのコントラスト比 |
| `fmtSize()` | B / KB / MB の境界 |
| `crc32()` | 既知の値との一致 |
| `runChecks()` | 各 err/warn の発火条件 |
| `lockUrl()` ＋ `unlockUrl()` | 往復して元のURLに戻る |

### 生成HTMLのスナップショットテスト 🤖

`buildHtml()` の出力に対して、文字列検索で確認：

- `__` で始まるプレースホルダが残っていないか
- 合言葉の平文が含まれていないか（**最重要**）
- `<\/script` への変換ができているか
- 期待するメタタグが存在するか
- JSON-LD が `JSON.parse` できるか

### 導入する場合の推奨

- **Phase 2 と同時に導入しない**（変更点が多すぎて原因の切り分けができなくなる）
- Phase 2 完了後、コードを `src/` に分割するタイミングで Node.js の組み込み `node:test` を使う
  （**外部パッケージ不要**で、現在の「依存ゼロ」を維持できる）
- ブラウザ操作の自動化（Playwright 等）は当面不要。手動で十分
